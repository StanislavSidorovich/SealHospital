# Тюленья больница 🦭

Маленькая 3D-игра для Сабрины: лечи тюленят на льдине, обнимай их и собирай альбом пациентов.

**Играть:** https://stanislavsidorovich.github.io/SealHospital/

Работает на телефоне и планшете, в браузере, без установки. Можно добавить на главный экран: «Поделиться → На экран Домой».

## Как играть

1. Осмотри пациента лупой — води ею по тюленю, и на карте откроется, что болит.
2. Лечи: у каждого лечения своя маленькая игра — подержать градусник, налить сироп по рецепту, протереть ранку и приклеить пластырь, поймать рыбку в лунке, выбрать шарфик.
3. Если тюлень чихает — лови чих платочком, а то шапку сдует!
4. Когда всё вылечено — обними тюленя (нажми на него). Вылеченный пациент попадает в альбом.

## Запуск локально

Открыть `index.html` двойным щелчком — всё нужное (Three.js) лежит в `vendor/`.
Для разработки удобнее локальный сервер:

```bash
python -m http.server 8765
```

и открыть http://localhost:8765/

## Устройство

`index.html` (разметка) + `css/style.css` + `js/` (`data.js` данные и сохранение, `audio.js`, `world.js` сцена, `seal.js` тюлень и предметы, `minigames.js` мини-игры лечения, `game.js` ход игры) + `vendor/three.min.js`. Без сборщика и модулей: всё открывается двойным щелчком.
