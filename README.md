# Тюлений остров 🦭 (Seal Island)

Уютная браузерная 3D-игра для дочки: лечи тюленят на льдине, заведи своего малыша-тюленёнка, гуляй с ним по острову, спасай остров от Великого шторма и играй вместе с папой по сети. Раньше называлась «Тюленья больница» — отсюда адрес `SealHospital`, он остаётся прежним.

**Играть:** https://stanislavsidorovich.github.io/SealHospital/

Работает на телефоне, планшете и компьютере, прямо в браузере, без установки и без интернета (после первого открытия). Можно добавить на главный экран: «Поделиться → На экран Домой» (iPhone/iPad) или кнопка «📲 Поставить на экран» в ⚙️ настройках (Android).

## Как играть

1. Осмотри пациента лупой — води ею по тюленю, и на карте откроется, что болит.
2. Лечи: у каждого лечения своя маленькая игра — подержать градусник, налить сироп по рецепту, протереть ранку и приклеить пластырь, поймать рыбку в лунке, выбрать шарфик.
3. Когда всё вылечено — можно нарядить пациента и обнять его. Вылеченный попадает в альбом, а ты получаешь ракушки 🐚 для лавки.
4. После первой смены у тебя появится свой тюленёнок: корми, купай, укладывай спать, гладь и гуляй с ним — он растёт от малыша до взрослого.
5. На острове живёт целая история: почта от папы, сосед-пингвин, приключения на льдинах, подводная бухта, праздники, бой с ворчливой Тучей и в конце — 🌪️ Великий шторм, от которого остров спасают все друзья вместе. «📖 Книга острова» в углу экрана подскажет, что делать сегодня.
6. «💗 Играть вместе» — можно позвать папу или подругу по коду комнаты или по ссылке, и играть в парные игры одновременно из разных мест.

## Запуск локально

Игра не собирается — просто откройте `index.html` двойным щелчком, всё нужное (Three.js, PeerJS) уже лежит в `vendor/`.

Для разработки удобнее локальный сервер:

```bash
python -m http.server 8765
```

и открыть http://localhost:8765/

## Устройство проекта

Обычные `<script>`-файлы без сборщика и без модулей — так игра открывается и с `file://`. Порядок подключения в `index.html` важен: файлы делят общую область видимости.

- `index.html` + `css/style.css` — разметка и стили.
- `vendor/three.min.js`, `vendor/peerjs.min.js` — сторонние библиотеки (см. «Чужой код» ниже).
- `js/i18n.js` — язык интерфейса (RU/EN), `js/data.js` — сохранение и игровые данные.
- `js/world.js`, `js/seal.js` — сцена и тюлень.
- `js/minigames.js`, `js/shop.js`, `js/shift.js` — лечение, лавка, смена.
- `js/pet.js`, `js/walk.js`, `js/home.js` — свой тюленёнок, прогулки, домик.
- `js/adventure.js`, `js/neighbors.js`, `js/mail.js`, `js/holidays.js` — приключения, сосед, папина почта, праздники.
- `js/net.js`, `js/coop.js` и другие — игра по сети вдвоём (бой с Тучей, спасение потеряшек, подводная бухта и т.д.).
- `js/storm.js` — 🌪️ Великий шторм, финал истории (4 части).
- `js/story.js` — «Книга острова», сквозная история.
- `js/game.js` — общий ход игры, подключается последним.

Подробнее об устройстве сохранения, языках и правилах дизайна — в [CLAUDE.md](CLAUDE.md). План работ — в [ROADMAP.md](ROADMAP.md).

## Как добавить письмо от папы

Допиши строчку в конец списка `LETTERS` в [js/letters.js](js/letters.js), сохрани файл и сделай коммит + пуш в `main` — GitHub Pages обновится сам (браузер может показывать старый файл ещё минут десять). Формат поля описан в комментарии в начале файла.
